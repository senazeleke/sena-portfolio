# Donnie

**Ethiopia’s home marketplace** — rent and buy houses, apartments, land, and commercial spaces. Search live listings, save favorites, message agents, and publish properties from one app — in English, Amharic, and Afaan Oromoo.

Built as a full-stack product for **clients**, **agents**, and **admins**, with multilingual UI (English · አማርኛ · Afaan Oromoo).

Case study: `/projects/donnie`

---

## What it does

Donnie is a real-estate marketplace, not a brochure site. Clients browse Addis-style inventory (Bole, CMC, Old Airport, and more), filter by rent or sale, open a photo gallery, pin homes on a map, save favorites, and message the listing agent. Approved agents publish listings that go **live immediately** on the landing page. Admins approve new agents, own the catalog (property types and amenities), and can take listings down.

Prices are **ETB**. Listing titles and descriptions are stored in three languages.

## Roles

| Role | Can do |
|---|---|
| **Client** | Register/login immediately, search & filter, open listing detail + gallery, save favorites, message the agent, get live notifications |
| **Agent** | Register as pending until admin approval; then publish listings (go live on save), edit own inventory, mark rented/sold (with confirm), reopen to the market, reply to inquiries |
| **Admin** | Approve/suspend users, reject or restore listings, CRUD categories & amenities, platform stats, same marketplace browse as everyone else |
