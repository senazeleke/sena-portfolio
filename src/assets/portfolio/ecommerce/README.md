## My role

Internship at OICT Solutions (Addis Ababa). Storefront and GraphQL/REST API path: product filtering, image uploads, query performance.

| Focus | What I owned |
| :--- | :--- |
| **Frontend** | React storefront, responsive layout, advanced product filtering |
| **API** | GraphQL for product queries; REST fallback for file uploads |
| **Data & mail** | PostgreSQL indexing and load balancing; password-reset email via Mailtrap |

---

## What it does

Shoppers land on a React storefront, filter products, and browse quickly. GraphQL fetches only the fields each view needs. Image uploads fall back to REST when GraphQL cannot carry the file.

---

## Tech stack

**Frontend:** React, responsive UI, product filtering  
**Backend:** Node.js, Express, GraphQL, REST fallback, PostgreSQL  
**Other:** Mailtrap, load balancing, database indexing
