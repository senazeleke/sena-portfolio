# Famcon Construction

**Enterprise platform & custom CMS for Famcon General Construction Work PLC**

Full-stack enterprise web application featuring trilingual localization (English, Amharic, Afaan Oromoo), a self-service client quotation portal, and role-based admin CMS with real-time lead analytics.

Full brief: `docs/companies/famcon/PORTFOLIO_CASE_STUDY.md`
